# Project Summary
The Myanmar Swine Livestock Co., Ltd. project aims to develop a corporate website for Myanmar's first Grandparent Stock (GP) breeder, producing over 38,000 commercial pigs annually. The project prioritizes sustainability through green energy solutions, such as solar and biogas systems, enhancing biosecurity and reducing dependence on the power grid. The website functions as a platform for price updates, company news, and serves as a knowledge hub for swine livestock, while also supporting multiple languages for broader accessibility.

# Project Module Description
- **Backend**: Previously managed data for site settings, pig prices, and knowledge articles using a CMS framework. (Note: Currently not in use as the site is static.)
- **Frontend**: A dynamic single-page application using React and Vite, now fully transitioned to a static HTML site. It provides a user-friendly interface for accessing company information, product offerings, and sustainability initiatives. The site supports real-time updates and multiple languages through a new language switching feature.
- **Admin Panel**: Previously allowed authorized users to manage content, prices, and site settings. (Note: This feature is no longer applicable as the project is now static.)

# File Description Inventory
- **app/backend/main.py**: Main entry point for the backend service (currently not in use).
- **app/frontend/src/App.tsx**: Main application component for the frontend, now redirects to the static HTML page.
- **app/frontend/src/pages/Index.tsx**: Redirects to the static HTML page.
- **app/frontend/public/static-site/index.html**: Contains the fully static HTML version of the website with embedded translations for multiple languages.
- **app/frontend/src/components/**: Contains reusable UI components such as Header, Footer, and various UI elements.
- **app/backend/requirements.txt**: Lists Python dependencies for the backend service (currently not in use).
- **app/frontend/package.json**: Lists Node.js dependencies for the frontend application.
- **app/frontend/.env**: Contains environment variables for the application title and description.

# Usage
1. **Install Dependencies**:
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - Build the frontend:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the frontend application:
     ```
     pnpm run dev
     ```
