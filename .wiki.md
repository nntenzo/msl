# Project Summary
The Myanmar Swine Livestock Co., Ltd. project is focused on creating a comprehensive corporate website for the leading Grandparent Stock (GP) breeder in Myanmar, with an annual production of 38,000 commercial pigs. The project emphasizes sustainability through green energy solutions, including solar and biogas systems, which enhance biosecurity and reduce dependence on the power grid. The website serves as an information platform for price updates, company news, and a knowledge hub for swine livestock, while also facilitating customer inquiries through a contact form.

# Project Module Description
- **Backend**: Manages data for site settings, pig prices, and knowledge articles using a CMS framework. It now includes functionality for handling contact form submissions and sending email notifications.
- **Frontend**: Offers a user-friendly interface for accessing company information, product offerings, and sustainability initiatives, supporting multiple languages.
- **Admin Panel**: Allows authorized users to manage content, prices, and site settings.

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `app/backend` directory and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - Build the frontend:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service:
     ```
     uvicorn main:app --reload
     ```
   - Start the frontend application:
     ```
     pnpm run dev
     ```
