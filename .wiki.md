# Project Summary
The Myanmar Swine Livestock Co., Ltd. project aims to develop a corporate website for Myanmar's first Grandparent Stock (GP) breeder, which produces over 38,000 commercial pigs annually. The project emphasizes sustainability through green energy solutions, including solar and biogas systems, while enhancing biosecurity and reducing reliance on the power grid. The website serves as a platform for price updates, company news, and a knowledge hub for swine livestock, supporting multiple languages for broader accessibility.

# Project Module Description
- **Frontend**: The project features a fully static HTML site, providing a user-friendly interface for company information, product offerings, and sustainability initiatives. It includes a language switching capability implemented entirely with client-side JavaScript for real-time updates without server dependencies.

# File Description Inventory
- **app/frontend/public/static-site/index.html**: Contains the fully static HTML version of the website with embedded translations for multiple languages, including updated contact details.
- **app/frontend/src/App.tsx**: Main application component for the frontend, now redirects to the static HTML page.
- **app/frontend/src/pages/Index.tsx**: Redirects to the static HTML page.
- **app/frontend/src/components/**: Contains reusable UI components such as Header, Footer, and various UI elements.
- **app/frontend/package.json**: Lists Node.js dependencies for the frontend application.
- **index.html**: Root-level static HTML file for easy access on platforms like GitHub Pages, updated with contact details.

# Technology Stack
- **Frontend**: Pure HTML, CSS, and vanilla JavaScript (no frameworks or dependencies)

# Usage
1. **Install Dependencies**:
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - Build the frontend:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the frontend application:
     ```
     pnpm run dev
     ```
