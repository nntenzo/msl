# Project Summary
The Myanmar Swine Livestock Co., Ltd. project is focused on creating a dynamic corporate website for Myanmar's first Grandparent Stock (GP) breeder, which produces over 38,000 commercial pigs annually. The company emphasizes sustainability through green energy solutions, including solar and biogas systems, to improve biosecurity and minimize reliance on the power grid. The website serves as a platform for price updates, company news, and a knowledge hub for swine livestock.

# Project Module Description
- **Backend**: Manages data for site settings, pig prices, and knowledge articles using a CMS framework.
- **Frontend**: A dynamic single-page application using React and Vite, providing a user-friendly interface for accessing company information, product offerings, and sustainability initiatives. It supports real-time updates and multiple languages.
- **Admin Panel**: Allows authorized users to manage content, prices, and site settings.

# File Description Inventory
- **app/backend/main.py**: Main entry point for the backend service.
- **app/frontend/src/App.tsx**: Main application component for the frontend, now redirects to the static HTML page.
- **app/frontend/src/pages/Index.tsx**: Redirects to the static HTML page.
- **app/frontend/public/static-site/index.html**: Contains the fully static HTML version of the website.
- **app/frontend/src/components/**: Contains reusable UI components such as Header, Footer, and various UI elements.
- **app/backend/requirements.txt**: Lists Python dependencies for the backend service.
- **app/frontend/package.json**: Lists Node.js dependencies for the frontend application.
- **app/frontend/.env**: Contains environment variables for the application title and description.

# Technology Stack
- **Backend**: Python, FastAPI, SQLAlchemy
- **Frontend**: React, TypeScript, Vite
- **Database**: PostgreSQL
- **Deployment**: Docker, Cloud Services

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `app/backend` directory and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - Build the frontend:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service:
     ```
     uvicorn main:app --reload
     ```
   - Start the frontend application:
     ```
     pnpm run dev
     ```
