# Project Summary
The Myanmar Swine Livestock Co., Ltd. project aims to develop a comprehensive corporate website for the leading Grandparent Stock (GP) breeder in Myanmar, producing 38,000 commercial pigs annually. The project emphasizes sustainability through green energy solutions, such as solar and biogas systems, enhancing biosecurity and reducing reliance on the power grid. The website serves as an information hub for price updates, company news, and swine livestock knowledge, while also facilitating customer inquiries through a contact form.

# Project Module Description
- **Backend**: Manages data for site settings, pig prices, and knowledge articles using a CMS framework. It includes functionality for handling contact form submissions and sending email notifications, along with a new module for managing site settings.
- **Frontend**: Provides a user-friendly interface for accessing company information, product offerings, and sustainability initiatives, supporting multiple languages.
- **Admin Panel**: Allows authorized users to manage content, prices, and site settings.

- **Frontend**: React, TypeScript, Vite
- **Database**: PostgreSQL
- **Deployment**: Docker, Cloud Services

# Usage
1. **Install Dependencies**:
   - For the backend, navigate to the `app/backend` directory and run:
     ```
     pip install -r requirements.txt
     ```
   - For the frontend, navigate to the `app/frontend` directory and run:
     ```
     pnpm install
     ```

2. **Build the Project**:
   - Build the frontend:
     ```
     pnpm run build
     ```

3. **Run the Application**:
   - Start the backend service:
     ```
     uvicorn main:app --reload
     ```
   - Start the frontend application:
     ```
     pnpm run dev
     ```
